# Original archive audit and reconstruction status

Six supplied archives were inspected directly. The private source-reference package contains inventories and the original model/flow definitions. **It is not intended for public distribution.**

This package contains independently authored SQL, M, DAX examples, synthetic input data, executable tests, report-page maps, and design explanations. Examples are **not production exports**, and reconstructed schemas may intentionally differ from their internal counterparts.

The project README files distinguish verified architecture visible in the sources from illustrative public implementations. Not every original measure is reproduced line-for-line; that would expose employer implementation and potentially sensitive business logic. The private reference preserves the source definitions for authorized internal review.
